# Day 5 – MySQL 8.4 Assignment

**Student:** Kavya D

This folder contains three beginner-friendly SQL case studies. Each set has a schema file, sample data, queries/tests and an ER diagram.

## Folder contents
- `Set-1-Retail-Inventory`: retail stock database
- `Set-2-Bank-Accounts`: bank account database
- `Set-3-Hospital-Records`: hospital patient visit database

## How to run
1. Open MySQL Workbench and connect to MySQL 8.4.
2. Open one set's `schema.sql` and execute it.
3. Execute that set's `seed_data.sql`.
4. Execute `operations_and_tests.sql`.
5. For Set 1, run each statement in `failing_inserts.sql` separately. Each statement is supposed to produce an error.

Run one set at a time. Each set uses a different database name.

The examples use made-up sample data for learning. The ER diagrams are in Mermaid format and can be viewed on GitHub.
